# Composer Workflow — releases

Installers and automatic updates for Composer Workflow.

Download the latest version from [Releases](https://github.com/Nineworldsapart/composer-workflow-releases/releases/latest):

- Apple silicon Macs (M1 and later, macOS 12+): the `arm64.dmg`
- Intel Macs (macOS 12+): the `x64.dmg`
- Windows PCs (64-bit): `Composer-Workflow-Setup-<version>.exe` (first time: More info, then Run anyway)

A serial number is needed to activate the app.
