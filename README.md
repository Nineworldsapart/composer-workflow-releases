# Composer Workflow — releases

Installers and automatic updates for Composer Workflow (macOS 12 or later).

Download the latest version from [Releases](https://github.com/Nineworldsapart/composer-workflow-releases/releases/latest):

- Apple silicon Macs (M1 and later): the `arm64.dmg`
- Intel Macs: the `x64.dmg`

A serial number is needed to activate the app.
